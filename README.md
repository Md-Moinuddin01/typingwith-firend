# ⌨️ TypeFlow – Modern Typing Practice & Challenge Platform
 
<img width="1885" height="945" alt="typing website file" src="https://github.com/user-attachments/assets/2d349a97-96c1-48f7-acec-846393ca3c00" />

TypeFlow is a modern and responsive typing practice platform designed to help users improve their typing speed, accuracy, and consistency. The application provides multiple practice modes, real-time performance tracking, customizable test durations, and multiplayer typing challenges.

## 🚀 Features

### 🎯 Typing Practice Modes
Choose from different typing categories:

- **Words** – Common everyday words
- **Numbers** – Numeric typing practice
- **Commas** – Punctuation-focused exercises
- **Quotes** – Short sentence practice
- **Mixed** – Combination of words, numbers, and punctuation

### ⏱ Custom Test Duration
Select your preferred typing session:

- 1 Minute
- 2 Minutes
- 3 Minutes
- 4 Minutes
- 5 Minutes

### 📊 Real-Time Statistics
Track your performance instantly:

- **WPM (Words Per Minute)**
- **Accuracy Percentage**
- **Error Count**
- **Remaining Time**

### 🏆 Multiplayer Challenges
Compete with friends or other users:

- Create challenge rooms
- Join existing challenge codes
- Real-time race experience
- Compare results instantly

### 🌙 Modern UI
- Dark theme interface
- Responsive design
- Smooth animations
- Clean typography
- Mobile-friendly layout
