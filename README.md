TypeFlow is a simple typing practice and multiplayer typing challenge web app. Users can practice typing, play typing games, and race with friends using a challenge code.

## Features

- Typing practice with multiple modes:
  - Words
  - Numbers
  - Commas
  - Quotes
  - Mixed
- Live typing test result
  - WPM
  - Accuracy
  - Errors
  - Time
- Arcade typing games
  - Letter Fall
  - Word Rain
  - Bounce Keys
  - Sprint Line
  - Memory Flash
  - Number Rush
- Multiplayer typing challenge
  - Create challenge code
  - Join challenge code
  - Race with friends on the same server
- Local server support with Node.js

## Tech Stack

- HTML
- JavaScript
- Node.js
